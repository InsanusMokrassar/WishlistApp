Adaptation: retain the existing exception boundary and delegate classification to Ktor, without registering status handlers that rewrite explicitly returned responses. Reject the documentation's illustrative interpolation of a Throwable into response text because these routes handle private inputs.

The [Kotlin ensureActive API](https://kotlinlang.org/api/kotlinx.coroutines/kotlinx-coroutines-core/kotlinx.coroutines/ensure-active.html) supports an explicit cancellation check when a dependency returns without suspending cooperatively.
