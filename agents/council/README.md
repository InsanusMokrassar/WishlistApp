# Portable Expert Council

Copy this entire directory plus [PROTOCOL](../PROTOCOL.md) and [MODELS](../MODELS.md), preserving relative paths. Those documents form the complete portable unit. The receiving repository supplies artifact storage, deterministic encoding, evidence snapshots, execution/isolation receipts, capability bindings and delivery without changing semantics. Project instructions, tooling, commit policy and runtime engines are not mandatory imports.

Entry: accepted Planning facts, stable acceptance criteria, resolved questions, configured applicability and frozen common evidence. Exit: a verified CONSENSUS reference seal identifying the unanimously accepted plan, or a complete blocking terminal package. Only the former enables implementation.

Read [PROTOCOL](../PROTOCOL.md), [MODELS](../MODELS.md), [COMMON](COMMON.md), then the selected contract: [Architect](ARCHITECT.md), [Programmer](PROGRAMMER.md), [Security](SECURITY.md), [Designer](DESIGNER.md), [Facilitator](FACILITATOR.md), or [Sealer](SEALER.md). All specialists receive the same complete instruction bundle although their active perspective differs. Run [CHECKS](CHECKS.md) when copying or changing the unit.

Architect is one technical perspective, not the umbrella Architecturing/Council stage. Four default specialists propose, review and consent; Facilitator and Sealer have zero technical votes. Added or omitted specialists require explicit configuration and applicability evidence before freezing, never omission by nonresponse.

Existing records remain immutable. Already-started legacy cycles may finish under their recorded contract; new Architecture entries require the council. Rollback preserves records and starts new attempts under the chosen version, never reused signatures.

The rationale is auditable convergence: common blind evidence limits cross-contamination, attributed candidates preserve alternatives, originator dispositions protect dissent, complete fresh reviews bind revisions, and the reference seal preserves accepted bytes. No claim is made about guaranteed model correctness or unobserved runner isolation.
